# 产品工作台部署说明

## 生产环境

入口为 `https://celiawang.fun`，服务器为腾讯云 `124.221.118.122`。阿里云 DNS 的 `@` 和 `www` A 记录指向该 IP；HTTP 和 `www` 统一跳转至主域名 HTTPS。

前端与 Express API 由同一域名访问。后端仅监听 `127.0.0.1:3001`，由 Nginx 转发。云 MySQL 8.4 容器 `mysql84` 仅将 3306 绑定到本机，使用已有独立数据库 `friend_product_workbench`，无需 SSH 隧道。上线时沿用现有账号、密码和业务数据，启动迁移不会覆盖已有记录。

## 目录与服务

| 内容 | 位置 |
| --- | --- |
| 发布版本 | `/opt/product-workbench/releases/<版本时间>/` |
| 当前版本软链接 | `/opt/product-workbench/current` |
| 独立 Node.js 24 LTS | `/opt/product-workbench/runtime/bin/node` |
| 运行配置 | `/etc/product-workbench.env` |
| 数据库密码文件 | `/etc/product-workbench/mysql_password.txt` |
| TLS 证书和私钥 | `/etc/product-workbench/tls/` |
| 运行数据目录 | `/var/lib/product-workbench/` |
| 数据库备份 | `/var/backups/product-workbench/` |

应用以无登录权限的 `workbench` 用户运行；源码和依赖由 root 管理。密码文件只允许 root 与 workbench 读取，证书私钥只允许 root 读取。系统原有 Node.js 与其他 Nginx 配置保持独立。

`product-workbench.service` 配置开机启动和失败重启。`product-workbench-backup.timer` 每天北京时间 03:00 执行整个项目数据库备份，包含附件；错过执行时间将在恢复后补一次。备份不自动删除，需要监控磁盘容量并定期拷贝到独立存储。

## 发布和更新

1. 本地运行 `npm test`、`npm --prefix server test` 和 `npm run build`。
2. 将 `dist/`、`server/src/`、`server/migrations/`、后端 package 文件及 `deploy/` 上传到新的发布版本目录。不要上传本机 `.env`、`.runtime`、SSH 私钥、证书私钥或 `node_modules`。
3. 在版本的 `server/` 目录使用独立 Node.js 运行时执行 `npm ci --omit=dev`，禁止复用 macOS 的依赖目录。
4. 按 `deploy/production.env.example` 安装私有配置，将证书与数据库密码单独安装到上述受限目录。首次部署先备份已有数据库。
5. 将 `current` 软链接指向新版本，安装 `deploy/` 中的 systemd 服务、备份脚本和 Nginx 配置，执行 `systemctl daemon-reload`、`nginx -t`。
6. 启用应用和备份定时器，重启应用后核实健康接口，再重新加载 Nginx。
7. 验证主域名 HTTPS、HTTP/www 跳转、登录、权限和真实数据。更新失败时将软链接切回旧版本并重启；涉及数据库结构更改时须按迁移另行评估回退。

常用操作：

```bash
systemctl status product-workbench
journalctl -u product-workbench -n 100 --no-pager
curl --fail http://127.0.0.1:3001/api/health
systemctl restart product-workbench
nginx -t && systemctl reload nginx
systemctl start product-workbench-backup
systemctl list-timers product-workbench-backup.timer
```

## 安全和证书

登录 Cookie 使用 HttpOnly、SameSite 和生产环境 Secure；写请求检查 Origin 和 CSRF。应用只信任本机反向代理，Nginx 覆盖客户端提供的转发地址。未登录不可访问工作空间与附件。生产环境请使用管理员设置过的正式密码，离线演示密码无法用于云数据库。

当前上传的证书覆盖 `celiawang.fun` 和 `www.celiawang.fun`，于 **2026-12-29 15:59:59（北京时间）** 到期。需提前在阿里云续签，更新 `/etc/product-workbench/tls/` 的证书与匹配私钥，执行 `nginx -t` 后 reload；当前没有自动签发续期流程。

## 数据与已知边界

工作台前端通过 `/api/workspace` 获取团队快照并在前端筛选分页；独立的服务端分页接口已提供。数据增大时可切换至分页接口。单个附件限制 1 MB，图片与普通附件各最多 12 个，未保存附件 24 小时清理。

所有业务时间采用 Asia/Shanghai。提醒在启动时及每小时扫描，覆盖到期前 3 天、当天与逾期，按事项、成员、日期去重。删除事项为逻辑删除，审计保留；界面不提供恢复已删除事项。历史事项引用的基础数据请停用，不允许强制删除。

数据库备份包含账号和业务附件，仅保存在服务器受限目录，不提交 GitHub。异地备份、恢复演练、邮件短信、外部推送和 CI/CD 尚未配置。
