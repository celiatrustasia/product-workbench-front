# 产品工作台 · 前端原型

采用方案 A「精密控制台」的布局与蓝色视觉。当前阶段是前后端分离的前端演示，不连接线上服务。

## 本地运行

```bash
npm install
npm run dev
```

默认地址为 `http://localhost:5173/`。`npm run build` 可检查 TypeScript 并生成静态构建。

如果不想启动服务，可以直接双击项目根目录中的 `产品工作台-直接打开.html`。该文件由 `npm run build` 自动生成，已经内嵌全部样式和脚本；根目录原有的 `index.html` 是 Vite 源码入口，不能作为普通静态网页直接打开。

也可以双击 `启动本地预览.command`，脚本会在 `http://127.0.0.1:5174/` 启动预览并自动打开浏览器。预览期间请保持脚本打开的终端窗口运行。

## 页面与操作

工作台、需求池（表格和看板）、任务管理（表格和看板）、详情、创建编辑、通知中心，以及管理员可见的平台、人员、字典管理均可操作。工作台通过环形图完整汇总本周重点需求（待评估、设计中、研发中、测试中、已上线）和本周重点任务（待开始、进行中、阻塞、已完成、挂起）的数量分布。

管理员可以编辑、删除需求、任务、平台、成员和字典选项；删除前会二次确认，仍被事项引用的平台或成员会阻止删除，删除需求时会保留关联任务并解除关联。平台支持直接拖拽行调整展示顺序。任务支持关联需求、多个里程碑、附件预览上传（单文件 1 MB）、负责人和多个参与人。重点事项显示“手动重点”和“本周节点”来源标签。界面兼顾 PC 与手机宽度。

## 后端对接边界

当前数据模型在 `src/types.ts`，初始数据在 `src/data/seed.ts`，状态、数据操作和演示登录集中在 `src/data/workspace.tsx`。下一阶段可在这一层接入 API，并将认证与权限验证移至服务端。提醒目前为站内预置消息及事项分派变更消息；定时临期提醒需由后端任务实现。附件目前是浏览器本地 Data URL，正式环境应改为对象存储。
